# Movia Desktop v1.2.1

Movia 1.2.1 removes the Windows desktop companion widget completely. Movia now
opens one main application window only, including when an obsolete shortcut
passes `--widget`. Portable Installed upgrades remove obsolete widget shortcuts,
startup entries, and preferences without touching the event database.

Overview uses the freed space for a month-navigable calendar and a balanced
summary showing active events, archived events, events this month, and the next
event date. Event dates are highlighted and open their related event.

Settings retains Appearance, Application Updates, Data, and About. English,
Arabic RTL, light/dark themes, navigation, local SQLite data, JSON portability,
and verified Portable Installed updates remain supported.
