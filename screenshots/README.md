# Screenshots

`design-concept.png` is the visual direction used to implement the desktop
interface. The remaining images capture the built application dashboard,
calendar, event form, and Arabic localization. They contain no personal event
data.

The implementation was matched to the concept in:

- sidebar width, navigation order, and selected state
- toolbar search/sort/add-event hierarchy
- large next-event countdown panel
- upcoming-event list density and category accents
- right-side calendar anatomy and event dots
- true light surface palette, restrained borders, and 16 px corner geometry
