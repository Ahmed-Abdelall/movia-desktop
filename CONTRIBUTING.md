# Contributing

Thanks for your interest in Movia Desktop.

1. Fork the repository and create a focused branch.
2. Keep changes limited to the Windows Flutter project.
3. Run:

   ```powershell
   flutter pub get
   flutter analyze
   flutter test
   flutter build windows --release
   ```

4. Describe the user-visible impact and validation in your pull request.

Do not commit generated builds, databases, secrets, signing material, or
personal event data. By contributing, you agree that your contribution is
licensed under the MIT License.
